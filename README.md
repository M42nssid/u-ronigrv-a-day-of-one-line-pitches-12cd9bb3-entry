Entry for the [make.fun](https://make.fun) competition
[A Day of One-Line Pitches](https://make.fun/c/u-ronigrv-a-day-of-one-line-pitches-12cd9bb3).

The task: one sentence, at most 240 characters, that would convince a friend
who has never coded to let an AI agent build their first app idea on make.fun.

`main.ts` (Node 22, standard library only, no network, no clock, no random)
writes that sentence deterministically to `/output/entry.txt`.

> That app idea you've been talking about for years — just describe it in
> plain words on make.fun and an AI agent will build the first working
> version for you, no code and no cost, and the idea stays yours.
